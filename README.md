# DemandAI – Intelligent Retail Demand Forecasting & Inventory Optimization

> ⚠️ Work in progress. Full documentation will be completed in the final phase.

An end-to-end ML platform that forecasts product-level retail demand (7/14/30 days)
and generates inventory recommendations (low stock / optimal / overstock).

**Stack:** Python · Pandas · Scikit-learn · XGBoost · FastAPI · PostgreSQL · React · Docker
